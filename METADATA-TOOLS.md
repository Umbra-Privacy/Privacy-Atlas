## Metadata Tools - By Umbra

### File & Document Metadata

- MAT2 - https://github.com/jvoisin/mat2 - Removes metadata from images, documents, audio, and other files.
- ExifTool - https://exiftool.org/ - Reads, edits, and removes metadata across many file formats.
- ExifCleaner - https://exifcleaner.com/ - Removes metadata from photos, videos, and PDFs.
- MetadataZero - https://github.com/metadatazero/metadatazero - Removes metadata from photos, videos, and PDF files.
- Dangerzone - https://dangerzone.rocks/ - Sanitizes untrusted documents and removes embedded metadata.
- Privacy Guides: Data Redaction - https://www.privacyguides.org/en/data-redaction/ - Explains metadata removal and personal-information redaction.

### Photo & Image Metadata

- Exif.tools - https://exif.tools/ - Displays EXIF metadata embedded in image files.
- Jeffrey’s Image Metadata Viewer - https://exif.regex.info/exif.cgi - Inspects image metadata and camera information.
- Metadata2Go - https://www.metadata2go.com/ - Displays metadata embedded in uploaded files.
- ImageOptim - https://imageoptim.com/ - Optimizes images and removes unnecessary metadata.
- ExifEraser - https://github.com/Tommy-Geenexus/ExifEraser - Removes image metadata on Android.

### Email Metadata & Headers

- MXToolbox Email Header Analyzer - https://mxtoolbox.com/EmailHeaders.aspx - Analyzes email headers, routing details, and mail servers.
- Google Admin Toolbox Messageheader - https://toolbox.googleapps.com/apps/messageheader/ - Analyzes email delivery paths and header information.
- RFC 5322 - https://www.rfc-editor.org/rfc/rfc5322 - Documents Internet email message formats and header fields.
- RFC 6973 - https://www.rfc-editor.org/rfc/rfc6973 - Explains privacy considerations, including metadata and data minimization.

### Browser Fingerprinting & Online Tracking

- EFF Cover Your Tracks - https://coveryourtracks.eff.org/ - Tests browser tracking and fingerprinting exposure.
- BrowserLeaks - https://browserleaks.com/ - Tests browser-exposed IP, DNS, WebRTC, and fingerprint information.
- Browser Fingerprint Test - https://browserfingerprint.org/ - Checks browser fingerprint signals and network exposure.
- AmIUnique - https://amiunique.org/ - Measures how distinctive your browser fingerprint appears.
- CreepJS - https://abrahamjuliot.github.io/creepjs/ - Examines browser fingerprinting and detectable browser characteristics.
- PrivacyTests.org - https://privacytests.org/ - Compares privacy protections across web browsers.

### Network & Connection Metadata

- DNS Leak Test - https://www.dnsleaktest.com/ - Checks which DNS resolvers your connection exposes.
- BrowserLeaks WebRTC Test - https://browserleaks.com/webrtc - Checks IP-address exposure through WebRTC.
- ipleak.net - https://ipleak.net/ - Checks public IP, DNS, and WebRTC leaks.
- Tor Project: Support - https://support.torproject.org/ - Explains Tor privacy, anonymity, and traffic limitations.

### Academic Research & Learning

- Privacy Enhancing Technologies Symposium (PETS) - https://petsymposium.org/ - Publishes research on privacy technologies and metadata protection.
- USENIX Security - https://www.usenix.org/conferences/byname/108 - Publishes computer-security and privacy research.
- Google Scholar - https://scholar.google.com/ - Finds academic studies on metadata leakage and privacy.
- arXiv: Cryptography and Security - https://arxiv.org/list/cs.CR/recent - Provides research papers on cryptography and security.
