# BROWSERS LIST - By UMBRA

## Tor Browser

1. **Official Website:** https://www.torproject.org/
2. **Open Source:** Yes
3. **Storage:** Local device
4. **E2EE:** HTTPS support through HTTPS-Only mode / HTTPS Everywhere functionality
5. **Security Model:** Onion routing, traffic encryption between Tor relays, anti-tracking, fingerprinting resistance
6. **Platforms:** Windows, macOS, Linux, Android
7. **Independent Security Audits:** Security reviews and audits have been conducted; see official Tor Project documentation
8. **Last Reviewed:** 2026-10-20

### Strengths
- Hides the user's IP address from destination websites.
- Routes traffic through the Tor network.
- Includes anti-fingerprinting protections.
- Blocks many common tracking techniques.
- Open-source code allows public inspection.
- Provides access to `.onion` services.

### Weaknesses and Risks
- Browsing can be significantly slower than with conventional browsers.
- Logging into personal accounts can reveal the user's identity.
- Traffic leaving the Tor network can be exposed if the destination does not use HTTPS.
- Installing extra extensions may weaken privacy and fingerprinting protections.
- Malware on the device can compromise privacy.
- Tor does not guarantee complete anonymity.

### Has Tor Browser Ever Been Hacked?
- Tor Browser has had security vulnerabilities in the past, as have other browsers.
- A vulnerability does not necessarily mean the Tor network itself was compromised.
- Exploitation may expose users to deanonymization or code execution, depending on the vulnerability.
- Keep Tor Browser updated to receive security fixes.
- Check official advisories for confirmed incidents and patched vulnerabilities.

### Security References

### Overall Assessment
Tor Browser is a strong choice for users who prioritize anonymity, anti-tracking, and resistance to browser fingerprinting. Its protections are most effective when users keep the default settings, avoid unnecessary extensions, and maintain good operational security. It should not be treated as a guarantee of complete anonymity.

**Security Verdict:** Strong privacy and anonymity protections, but not immune to vulnerabilities, endpoint compromise, or user mistakes.
